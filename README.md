# Dino AI · 技术状态 / Tech State

给公司核心管理层看的技术状态页。周更、中英双语、单文件 HTML。

文件：`index.html`（双击打开，无需构建、无需联网、无外部依赖）
语言：右上角「中 / EN」，选择记在浏览器里

结构对齐产品里程碑页：页头 → 周轴（吸顶，W43 / W44 / W45+）→ 每周一个时间线节点（左侧竖线 + 圆点 + 周号，右侧标题、摘要，然后分**两块**）。

每周两块，用左侧竖条区分：

- **技术健康度**（绿条）：稳定性建设、交付质量、可观测性这类「把下限抬高」的活。内部按关卡分组：**DTTE**（下载到首课开课）/ **TETF**（首课开课到完课）/ **FTP**（完课到付费）/ 说清楚 / 技术基建。
- **技术探索**（橙条）：还没有答案、需要先验证再投入的活。不分组，平铺。

当前周：周轴深色块 + 橙色实心点 + 标题旁「进行中」标签，周号下面写周一到周五的日期。

**纯产品交付不进这页。** 例如发版、SKU 定价、挽留弹窗、麦克风交互专项、音素级标红标绿这类，属于产品里程碑页的内容，这里不重复。

## 每周怎么改

只改 `index.html` 底部 `<script>` 里的 `WK` 数组，其余不要动。

### 一个周节点

```js
{ id:'W43', href:'#w43', core:true,          // core:true = 当前周，橙色
  date:{zh:'本周',en:'This week'},
  range:{zh:'10/20 – 10/24',en:'Oct 20 – 24'},   // 周一到周五
  days:{zh:'周一 – 周五',en:'Mon – Fri'},        // 可选，第三行
  rail:{zh:'10/20 – 10/24',en:'Oct 20 – 24'},   // 吸顶周轴上显示的小字
  title:{zh:'本周交付',en:'This week'},
  story:{zh:'…{n}…{p0}…{p1}…{p2}…{un}…{done}…',
         en:'…'},                          // 摘要，六个占位符会自动填数
  items:[ … ] }
```

`story` 里的 `{p0}{p1}{p2}{un}{done}` 会按当周数据自动替换，正文里可以直接写。

### 一条事项

```js
{ t:{zh:'',en:''},        // 标题
  w:'董鹏',                // 负责人
  p:'P0',                 // P0 / P1 / P2；写 '—' 则不显示优先级
  d:{zh:'10-24',en:'Oct 24'},   // 日期取台账原文；写 '—' 则不显示日期
  gate:'entry',           // entry(DTTE) / hold(TETF) / pay(FTP) / voice / base(技术基建)
  kind:'bet',             // 只有探索项要写；不写默认算健康度
  done:true,              // 已完成：标题前打勾
  wip:true,               // 进行中：标题前显示进度环（当前周不必写，自动推断）
  doc:'https://…',        // 可选，这条事项的 Lark 文档；有的话标题变成链接
  dl:{zh:'',en:''} }      // 交付物，一行小字
```

**当前周（`core:true`）里的条目，只要没标 `done:true`，一律显示为进行中**，不用手写 `wip`。所以每周滚动时，只需要把做完的标成 `done:true`，其余自动带进度环。

`gate` 只影响它落在健康度的哪一组，顺序固定为：DTTE → TETF → FTP → 说清楚 → 技术基建。写了 `kind:'bet'` 的进探索块，不参与分组。

**有文档就要挂链接。** 事项的详细描述、验收标准在 Lark 文档里，页面只做索引；标题后面的 ↗ 就是入口。绝大多数文档在 `10月技术专项-30个项目` 这个节点下面。

### 每周滚动

1. 把第一个周节点整块删掉；
2. 第二个改成 `id:'W43'`、`core:true`，`href` 同步改成 `#w43`；
3. 末尾补一个空的 `W45+`，把这一周还没排期的事项放进去。

`W45+` 就是「没有承诺日期」的兜底栏，不要给它编日期。

---

## 两条硬规矩

1. **日期取台账原文。** 「本周」「下周」「10 月底」照抄，不推算；没有日期写 `'—'`。
2. **不编数。** 摘要里的人数和条数由 `items` 自动算，不要手写死。

---

## 以后要部署时

把 `index.html` 放到任意静态托管（GitHub Pages 最省事，和产品里程碑页同一套做法），
拿到固定 URL 后，把页脚「反馈」那一句换成 Lark 文档或表单链接。

中英切换是纯前端字符串切换，部署时不需要两份文件。
